# Contributing

Thanks for your interest in the UniFi Network SIEM!

## Where the code lives

Development happens on an internal GitLab instance. This GitHub repository is an **automatic, read-only mirror** of it: every merge on GitLab is pushed here shortly after, and anything pushed or merged directly on GitHub would be overwritten by the next mirror update. GitHub remains the public home for issues and discussion.

## Bug Reports & Feature Requests

We welcome bug reports and feature requests via [GitHub Issues](https://github.com/Ward-Software-Defined-Systems/UniFI-Network-SIEM/issues). Please include:

- A clear description of the problem or suggestion
- Steps to reproduce (for bugs)
- Your environment (OS, Node.js version, UniFi controller version)

## Pull Requests

**We are not accepting external pull requests at this time.** This project is actively developed by Ward Software Defined Systems and follows an internal development workflow. Because GitHub is a mirror, a pull request opened here can't be merged here — if you have a change in mind, open an issue describing it and we'll take it from there.

You're welcome to:

- **Fork** the repo and modify it for your own use
- **Open issues** to suggest changes — if we agree, we'll implement them
- **Star** the repo if you find it useful

## Code of Conduct

Be respectful and constructive in all interactions. We reserve the right to close issues or block users who are disruptive.
